# 18 Claude Skills for Consulting-Grade Slide Design

A pack of 18 standalone Claude skills for building consulting-grade slides. Each skill teaches Claude one named slide-design method, from writing action titles to running a partner-grade review, so you can take rough content all the way to a clean, board-ready deck.

## Who this is for

Consultants, bankers, private equity and corporate strategy professionals who build dense, high-stakes slides under deadline pressure. The methods are the ones used on top-tier consulting decks: the Pyramid Principle, SCQA, MECE, action titles, the data-ink ratio, Gestalt alignment, ghost decks, and structured partner review. Each skill is genuinely distinct from the others, so you can install one, a group, or the whole set.

The skills cover four stages of slide design: getting the message and structure right, turning content into exhibits, applying visual craft, and reviewing and reworking to a senior standard. They pair naturally with Oria, which turns the resulting content into fully editable PowerPoint slides inside PowerPoint itself.

## What is inside (18 skills)

Message and structure

1. action-title-writer. Rewrites headlines into single-sentence action titles that state the so-what.
2. pyramid-storyline-builder. Structures the deck as a top-down Pyramid Principle argument with MECE supporting lines.
3. scqa-opening-framer. Builds the opening with Situation, Complication, Question, Answer.
4. executive-summary-builder. Builds a one-page summary that carries the recommendation, reasons, and ask.
5. ghost-deck-skeleton. Produces a skeleton deck of titled, empty slides to agree the story before designing.

Exhibit and data

6. exhibit-selector. Maps a message to the right chart, framework, or layout.
7. chart-to-message-mapper. Turns a raw chart into a message-driven exhibit with one highlight.
8. data-ink-reducer. Strips non-data ink so every mark carries meaning.
9. mece-layout-architect. Arranges slide content into a MECE structure with a logical reading order.
10. framework-slide-designer. Designs clean framework slides (2x2, value chain, flow, pyramid, matrix).

Layout and visual discipline

11. gestalt-alignment-and-grid. Cleans layout with a grid and Gestalt grouping.
12. callout-and-annotation-designer. Adds restrained callouts that direct the reader to the insight.
13. icon-discipline. Enforces one consistent, meaningful icon system.
14. color-and-brand-discipline. Applies a neutral base plus one accent, inside the brand template.
15. slide-density-balancer. Right-sizes how much each slide carries, splitting and merging as needed.

Review and rework

16. before-after-redesign. Rebuilds a weak slide into a clean one while preserving all content.
17. partner-review-checklist. Runs the deck through a partner-grade review and returns a prioritized fix list.
18. flow-and-page-tracker-auditor. Audits flow and adds dividers, a page tracker, and consistent headers.

## Install

1. Unzip this pack anywhere.
2. Add the skill folders to a Claude Project as Project Knowledge, or drop them into `~/.claude/skills/`. Add as many as you want: one skill, a group, or all 18.
3. In a conversation, name the skill you want Claude to run, for example "Use the action-title-writer skill on these slide headlines" or "Run the partner-review-checklist on this deck."

Each skill is one folder with a single `SKILL.md` file. Keep the whole set or pull out only the folders you need.
