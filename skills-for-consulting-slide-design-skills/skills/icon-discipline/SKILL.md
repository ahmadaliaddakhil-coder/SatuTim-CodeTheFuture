# Icon Discipline

## When to use
Use this when a deck has mismatched icons from different sets, icons that decorate without informing, or icons in too many colors and styles. Use it when a junior draft looks like a brochure. Use it to set an icon standard before building a deck.

## What it does
It enforces a single, coherent icon system: one style, consistent weight and size, used only where an icon aids comprehension. The result looks intentional and professional rather than busy or generic.

## Method
On a consulting slide, an icon should earn its place by speeding recognition, not fill space.

1. Decide if an icon is needed. An icon helps when it labels a repeated category the eye scans (a stage, a function, a risk type) or anchors a short concept. It does not help next to every bullet. Default to no icon unless it adds recognition speed.

2. Pick one icon family. Choose a single style: line icons or solid, one stroke weight, one corner treatment. Never mix line and solid, or two clip-art libraries, in one deck. Consistency is the whole point.

3. Size and align consistently. Use one or two icon sizes across the deck. Align icons to the grid and to the text they label. Equal optical size matters more than equal pixel size; adjust so they look balanced.

4. Keep icons monochrome. Render icons in a single neutral tone, with the accent reserved for the one icon that marks the important item. Multicolor icons compete with the data.

5. Make the metaphor literal and obvious. Use the plain, expected icon for a concept (a gear for operations, a shield for risk, a person for customer). Avoid clever or abstract icons that the reader must decode.

6. Keep detail appropriate. Use cleanly drawn, simple icons. Avoid both crude single-shape glyphs and over-detailed illustrations. The icon should read at slide size from across a room.

7. Do not let icons replace content. An icon is a label, not an argument. The text and data carry the meaning. If a slide is mostly icons, it is probably under-substantiated.

8. Audit the set. Lay every icon in the deck side by side. Remove duplicates of meaning, replace any off-style icon, and confirm one consistent family throughout.

## Inputs
- The deck or slide and its current icons.
- The categories or concepts that genuinely benefit from an icon.
- The brand or chosen icon style, if one exists.

## Output format
Return: which icons to keep, remove, or replace; the single icon family and stroke weight to standardize on; the size and alignment rule; the monochrome and accent rule; and a mapping of concept to recommended literal icon. Flag any slide where icons outnumber substance.

## Example
Draft: a workstreams slide with five icons from three different sets, two in color.
Discipline: replace all with one line-icon family at a single size; render in the neutral tone; keep an icon only on each of the five workstream headers (gear, chart, people, shield, flag); mark the at-risk workstream's flag icon in the accent; remove the decorative icons next to bullets.
